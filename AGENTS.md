# AGENTS.md — для контрибьюторов-моделей и людей

Офлайн-субтитры: видео на незнакомом языке → SRT рядом с файлом.
README.md — для пользователей, этот файл — для тех, кто меняет код.

## Команды

```sh
uv sync --all-extras          # окружение (Python 3.12 пин, uv сам скачает)
uv run pytest                 # все тесты, ~1 c, GPU не нужен
uv run ruff check src tests    # линт, единственный
uv run subvox --help
```

Дымовой прогон живыми моделями — обязателен для изменений в `asr`, `nllb`,
`lid`, `vad`, `model`, `cuda`:

```sh
uv run subvox detect  файл.webm
uv run subvox run файл.webm --to en
```

Тесты гоняются на подставных моделях (см. `tests/`) и не качают весов.
Скачивание моделей — только вручную и в smoke-прогонах.

## Архитектура — почему модули отдельные

Пайплайн — конвейер с одним направлением потока:

```
audio → vad → lid → asr → sentences → nllb → cues → subs → .srt
```

| Модуль | Зачем отдельный |
|---|---|
| `audio.py` | ffmpeg — subprocess-контракт; выбор дорожки `-map 0:N`, а не «первая попавшаяся» |
| `vad.py` | Нужен и LID, и ASR — не принадлежит ни одному из них |
| `lid.py` | Язык определяется **до** транскрипции: языковой токен стоит в промпте декодера, неверный токен = фонетическая каша |
| `asr.py` | Транскрипция с пословными таймкодами + три фильтра галлюцинаций |
| `sentences.py` | Единица перевода — предложение, не сегмент Whisper: Whisper рвёт фразы посередине |
| `nllb.py` | Единственный внешний вызов перевода; формат токенов — контракт |
| `cues.py` | Единица отображения — реплика; строится из перевода, не из оригинала |
| `subs.py` | Только запись, без логики нарезки |
| `langs.py` | Единственный слой нормализации языковых кодов |
| `cuda.py` | Предзагрузчик библиотек общий для Whisper и NLLB |
| `model.py` | Загрузка Whisper с прогоном-проверкой устройства |

## Инварианты — нарушать нельзя

1. **Языковые коды — только через `subvox.langs`.** Три пространства имён
   (ISO-639-1 у Whisper, FLORES-200 у NLLB, названия для людей) сводятся
   в одном месте. Хардкод кода в другом модуле — баг, даже если работает.
2. **Никакого тихого фолбэка на английский.** Непереводимый язык, неуверенный
   LID, пустой транскрипт — явные ошибки (`langs.NoTranslation`,
   `vad.NoSpeech`, `asr.TranscriptionError`), а не дефолт.
3. **Формат токенов NLLB — не трогать без прогона на живой модели.**
   Источник: `spm-куски + ["</s>", src_lang]`, префикс декодера `[tgt_lang]`.
   Это fairseq-наследие; «упрощение» ломает выбор языка выхода молча.
   Декодирование — через словарь токен→id (`tokenizers` не декодирует строки).
4. **Проверка устройства = реальный прогон, не факт создания модели.**
   Система может иметь CUDA 13 при собранном под 12 CT2: модель загрузится
   и упадёт на первом вычислении. Отсюда `_warmup`/пробный `translate_batch`.
5. **Порог VAD — лестница.** Речь поверх музыки не «тишина»: порог понижается,
   факт понижения доходит до пользователя (предупреждение в CLI, поле
   `vad_threshold` в JSON). Передаётся из LID в ASR явно.
6. **Перевод — по предложениям, CPS не урезается.** Перевод длиннее оригинала
   остаётся длинным: реплика делится на несколько с делением времени по
   символам. «Быстро читать» — предупреждение (`Cue.too_fast`), не обрезка.
7. **Пословные таймкоды точнее границ сегментов.** В предложениях и репликах
   берутся концы слов, не концы сегментов Whisper.

## Соглашения

- Python 3.12 (`requires-python = ">=3.12,<3.13"`): у `ctranslate2` и
  `faster-whisper` нет колёс под системный 3.14.
- GPU — опция `[gpu]`: `nvidia-cublas-cu12` + `nvidia-cudnn-cu12` в venv.
  Системные CUDA-пакеты не трогаются. Отсюда `cuda.py` и `ctypes.RTLD_GLOBAL`.
- Железо разработчика: RTX 3060 Ti, 8 ГБ VRAM. Отсюда `int8_float16`
  у обеих моделей и `BATCH_TOKENS = 4096`.
- Вычисления на GPU, тексты и кириллица в выводе и докстрингах — осознанно.
- Тесты: подставные модели с предзаписанными распределениями, ffmpeg —
  настоящий (он системный и лёгкий). Никаких моков сети.
- Ошибки в CLI — через `_fail` с кодом 1 и человеческим текстом, не traceback.

## Известные ограничения (v1, осознанные)

- Речь поверх громкой музыки: VAD ловит на пониженном пороге, но Whisper
  распознаёт плохо (`1.webm` — 4 слова из 10 секунд). Сообщается, не лечится.
- Simultaneous speech / перебивания — вне скоупа, один поток речи.
- NLLB-200 — CC-BY-NC-4.0, только некоммерческое использование.
- Молчаливых языков немного: `br, haw, la, mg` — распознаются, не переводятся.
