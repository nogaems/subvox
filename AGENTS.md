# AGENTS.md — для контрибьюторов-моделей и людей

Офлайн-субтитры: видео на незнакомом языке → SRT рядом с файлом.
README.md — для пользователей, этот файл — для тех, кто меняет код.

## Команды

```sh
uv sync --all-extras          # окружение (Python 3.12 пин, uv сам скачает)
uv run pytest                 # все тесты, ~1 c, GPU не нужен
uv run ruff check src tests    # линт, единственный
uv run subvox --help
```

Дымовой прогон живыми моделями — обязателен для изменений в `asr`, `nllb`,
`lid`, `vad`, `model`, `cuda`:

```sh
uv run subvox detect  файл.webm
uv run subvox run файл.webm --to en
```

Тесты гоняются на подставных моделях (см. `tests/`) и не качают весов.
Скачивание моделей — только вручную и в smoke-прогонах.

## Архитектура — почему модули отдельные

Пайплайн — конвейер с одним направлением потока:

```
audio → vad → lid → asr → sentences → nllb → cues → subs → .srt
```

| Модуль | Зачем отдельный |
|---|---|
| `audio.py` | ffmpeg — subprocess-контракт; выбор дорожки `-map 0:N`, а не «первая попавшаяся» |
| `vad.py` | Нужен и LID, и ASR — не принадлежит ни одному из них |
| `lid.py` | Язык определяется **до** транскрипции: языковой токен стоит в промпте декодера, неверный токен = фонетическая каша |
| `asr.py` | Транскрипция с пословными таймкодами + три фильтра галлюцинаций |
| `sentences.py` | Единица перевода — предложение, не сегмент Whisper: Whisper рвёт фразы посередине |
| `nllb.py` | Единственный внешний вызов перевода; формат токенов — контракт |
| `cues.py` | Единица отображения — реплика; строится из перевода, не из оригинала |
| `subs.py` | Только запись, без логики нарезки; формат (srt/vtt) — по расширению пути, проверяется рано |
| `langs.py` | Единственный слой нормализации языковых кодов |
| `cuda.py` | Предзагрузчик библиотек общий для Whisper и NLLB |
| `model.py` | Загрузка Whisper с прогоном-проверкой устройства |
| `paths.py` | Единственный модуль, знающий про ОС: данные, кеш, модели — per-user |
| `store.py` | Рабочие каталоги по хешу содержимого видео; индекс путей — в кеше |
| `pipeline.py` | Связь стадий с кешем: одна точка входа для команд CLI, ленивое аудио, честные ключи записей |

## Инварианты — нарушать нельзя

1. **Языковые коды — только через `subvox.langs`.** Три пространства имён
   (ISO-639-1 у Whisper, FLORES-200 у NLLB, названия для людей) сводятся
   в одном месте. Хардкод кода в другом модуле — баг, даже если работает.
2. **Никакого тихого фолбэка на английский.** Непереводимый язык, пустой
   транскрипт — явные ошибки (`langs.NoTranslation`, `asr.TranscriptionError`),
   а не дефолт. Неуверенный LID — предупреждение с альтернативами и советом
   `--from`, не тихая подмена: уверенность модели на шумном аудио не приговор.
   Речи нет (`vad.NoSpeech`): `run` пишет пустой файл (0 реплик) с явным
   предупреждением — покрытие полное, текст не выдумывается; `detect` и
   `transcribe` падают, потому что определять и распознавать нечего.
3. **Формат токенов NLLB — не трогать без прогона на живой модели.**
   Источник: `spm-куски + ["</s>", src_lang]`, префикс декодера `[tgt_lang]`.
   Это fairseq-наследие; «упрощение» ломает выбор языка выхода молча.
   Декодирование — через словарь токен→id (`tokenizers` не декодирует строки).
4. **Проверка устройства = реальный прогон, не факт создания модели.**
   Система может иметь CUDA 13 при собранном под 12 CT2: модель загрузится
   и упадёт на первом вычислении. Отсюда `_warmup`/пробный `translate_batch`.
5. **Порог VAD — лестница.** Речь поверх музыки не «тишина»: порог понижается,
   факт понижения доходит до пользователя (предупреждение в CLI, поле
   `vad_threshold` в JSON). Передаётся из LID в ASR явно. «Редкая речь»
   на стандартном пороге засчитывается только от
   `MIN_FALLBACK_SPEECH_SECONDS` (2 с): единичный всплеск короче — щелчок
   или музыка, а не повод отдавать его в ASR: там он превращается
   в галлюцинацию.
6. **Перевод — по предложениям, CPS не урезается.** Перевод длиннее оригинала
   остаётся длинным: реплика делится на несколько с делением времени по
   символам. «Быстро читать» — предупреждение (`Cue.too_fast`), не обрезка.
   Реплика, где после нарезки остаётся строка длиннее двух строк
   (`UNRENDERABLE`, 84 знака), — неразрывный бред модели: она пропускается
   целиком с предупреждением, тайминги соседних не сдвигаются. Токен
   43–84 знака остаётся переполнением строки: лучше край кадра, чем потеря
   текста.
7. **Пословные таймкоды точнее границ сегментов.** В предложениях и репликах
   берутся концы слов, не концы сегментов Whisper.

## Соглашения

- Python 3.12 (`requires-python = ">=3.12,<3.13"`): у `ctranslate2` и
  `faster-whisper` нет колёс под системный 3.14.
- GPU — опция `[gpu]`: `nvidia-cublas-cu12` + `nvidia-cudnn-cu12` в venv.
  Системные CUDA-пакеты не трогаются. Отсюда `cuda.py` и `ctypes.RTLD_GLOBAL`.
- Платформы: Linux — единственная проверенная. Windows и macOS
  спроектированы (`paths.py`), на реальном железе не проверялись.
  GPU — только Linux (маркер `sys_platform` у `[gpu]`, гвард в `cuda.py`):
  под Windows pip не может поставить cuBLAS — нужен CUDA Toolkit,
  под macOS GPU-колёс CTranslate2 не существует. Откат на CPU там —
  рабочий режим по дизайну, не баг и не то, что надо «чинить».
- `paths.models_dir()` — мини-хаб huggingface_hub: общий `blobs/` с
  относительными симлинками (дедупликация Xet-файлов), `.refs`-манифесты
  для сборки мусора. Мы этот каталог не обходим и не парсим — только
  передаём в `snapshot_download`/`download_root` и пользуемся
  возвращённым путём снапшота. На Windows без прав на симлинки хаб сам
  кладёт копии вместо ссылок — это его рабочий режим, не баг. Относительность
  ссылок делает каталог переносимым между машинами.
- Железо разработчика: RTX 3060 Ti, 8 ГБ VRAM. Отсюда `int8_float16`
  у обеих моделей и `BATCH_TOKENS = 4096`.
- Вычисления на GPU, тексты и кириллица в выводе и докстрингах — осознанно.
- Тесты: подставные модели с предзаписанными распределениями, ffmpeg —
  настоящий (он системный и лёгкий). Никаких моков сети. Живые модели,
  корпус и сеть — только в смоук-прогонах, не в `pytest`.
- Бюджет строки — 42 знака, две строки: Netflix Timed Text Style Guide
  (English USA). Отступления: без потолка 7 с на реплику (длину задаёт
  текст, не таймер), `MIN_DURATION = 1.0` как ориентир, `CPS_SOFT = 21`
  вместо 20. Короткая реплика при плотной речи — не дефект: пользователь
  ставит паузу. CPS — информация, а не критерий качества и не повод резать.
- Целевые языки — `en`, `ru`, максимум `de`, `fr`: все узкие письменности,
  бюджет 42 знака верен. CJK вне скоупа. Решения на будущее, когда цель
  станет `de`/`fr`: для `de` один композит длиннее 42 знаков — допустимое
  переполнение без переносов; для `fr` не рвать элизии (`l'`, `d'`, `qu'`)
  и кавычки `«…»`.
- Кеш стадий ключуется входами стадии: код и настройки модели, порог VAD,
  константы логики. Правка констант VAD инвалидирует LID/VAD, но не
  транскрипт: его ключ — выбранный `vad_threshold`, а не способ выбора.
- Смоук-видео: корзина живых файлов для длинных прогонов —
  `contrib/smoke-videos.md` (единственный источник ссылок, слоты
  с осями нагрузки и ожиданиями) и `contrib/fetch_smoke.py`
  (мультиплатформенный, идемпотентный; `.sh`/`.ps1` — тонкие обёртки).
  Зависимости хоста для инициализации тестов: uv, ffmpeg и JS-runtime
  для yt-dlp (deno или node) — без него YouTube режет загрузку 503-ми;
  скрипт сам ищет доступный runtime по PATH и передаёт его флагом
  `--js-runtimes`, нет ни одного — честная ошибка до старта.
  Солвер-скрипты JS-задач подтягиваются с GitHub
  (`--remote-components ejs:github`, рекомендация yt-dlp).
  Контракты скрипта запинены тестами (`tests/test_fetch_smoke.py`).
  Корзина лежит в `paths.smoke_dir()`, в git не входит. Ранние тестовые
  клипы (1.webm, 2.mp4, 3.webm) — из до-манифестной эпохи, живут у
  автора проекта вне репозитория; в смоук-прогонах не участвуют,
  для новых проверок — только корзина из манифеста.
- Полный прогон по корзине — `contrib/run_smoke.py`: строгий по умолчанию
  (отсутствующий слот — ошибка со списком; `--partial` — только для
  контрибьюторов с региональными блокировками), `--only` фильтрует слоты,
  `--report` пишет markdown-сводку. Журнал прогона, среда и тайминги
  остаются локально в `smoke/`, в git не входят: это не бенчмарк.
- Скачивание моделей — префетчем с анонсом и прогресс-барами:
  faster-whisper отключает бары (`disabled_tqdm`), поэтому модель
  префетчится напрямую через `snapshot_download` до `WhisperModel`.
  Анонс — колбэк `note`, пробрасываемый из CLI: библиотечные модули
  (`model.py`, `nllb.py`) ничего не печатают сами. Провал скачивания
  оборачивается в `ModelError`/`TranslationError` — CLI не ловит OSError.
- Ошибки в CLI — через `_fail` с кодом 1 и человеческим текстом, не traceback.
- Форматы субтитров: srt (по умолчанию) и vtt (`--format vtt`, для
  браузерного `<track>`). Писатель один, формат определяет расширение
  пути; путь проверяется до моделей (`subs.format_of`) — опечатка в `--out`
  не должна стоить минут транскрипции. ASS отвергнут: позиционирование
  и стили требуют диаризации, которой нет и которая вне скоупа.
- Распространение: wheel в GitHub Releases + установочный скрипт
  (PowerShell/shell), подтягивающий зависимости нужных версий до установки.
  Бандл в экзешник отвергнут сознательно: ffmpeg и CUDA-библиотеки в него
  не упаковать, а onefile распаковывается при каждом вызове CLI. Модели
  качаются при первом запуске в `paths.models_dir()`, рабочие файлы —
  `store.py` по хешу содержимого, регенерируемое — `paths.cache_dir()`.

## Известные ограничения (v1, осознанные)

- Речь поверх громкой музыки: VAD ловит на пониженном пороге, но Whisper
  распознаёт плохо (`1.webm` — 4 слова из 10 секунд). Сообщается, не лечится.
- Whisper LID не различает близкие языки и диалекты: кантонский уходит
  в `zh`, хинглиш — в `en`. Это граница модели, а не баг: уверенность
  высокая, порогами не лечится. Обход — `--from yue` / `--from hi`.
- Музыка без речи: порог «редкой речи» 2 с отсекает щелчки, но длинные
  музыкальные фрагменты с редкими вокализами всё ещё могут дать текст.
  Ожидание слота `fail-nospeech`: `vad.NoSpeech` до ASR, `run` пишет
  пустой `.srt` с предупреждением, `detect` — ошибка.
- Simultaneous speech / перебивания — вне скоупа, один поток речи.
- NLLB-200 — CC-BY-NC-4.0, только некоммерческое использование.
- Молчаливых языков немного: `br, haw, la, mg` — распознаются, не переводятся.
