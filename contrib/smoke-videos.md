# Корзина смоук-видео

Живые видео для смоук-прогонов subvox на длинных и сложных файлах.
Пять и сорок две секунды клипов ничего не доказывают — эта корзина
давит на конкретные места пайплайна.

**В git — только ссылки и метаданные.** Контент принадлежит авторам;
локальные копии — для тестов этой машиной, распространять их нельзя.

## Куда качается и как

`subvox.paths.smoke_dir()` — стандартное системное per-user место:
Linux `~/.local/share/subvox/smoke`, Windows `%LOCALAPPDATA%\subvox\smoke`,
macOS `~/Library/Application Support/subvox/smoke`; `SUBVOX_HOME`
переопределяет. Имена файлов — по слоту (`en-ted.mkv`), не по названию
видео: стабильные, читаемые, не зависят от переименования на YouTube.

Скачивание — идемпотентным скриптом (Linux/macOS):

```sh
contrib/fetch-smoke.sh
```

На Windows — та же команда вручную для каждого слота (uvx → uvx.exe
после установки; шаблон):

```powershell
uvx yt-dlp -f "bv*[height<=480]+ba/b[height<=480]/b" --merge-output-format mkv --no-overwrites -o "$env:LOCALAPPDATA\subvox\smoke\<слот>.%(ext)s" <ссылка>
```

Потолок 480p осознан: пайплайн ест только аудиодорожку, видео нужно
для проверки синхронности субтитров глазами в mpv — этого хватает.
Повторный запуск ничего не перезаписывает: существующий слот
пропускается. Формат контейнера после слияния — mkv; расширение у
однопоточных файлов может остаться нативным (.mp4/.webm).

## После скачивания

```sh
uv run subvox detect  ~/.local/share/subvox/smoke/ja-tokyo.*
uv run subvox run     ~/.local/share/subvox/smoke/en-ted.* --to ru
```

Записи кеша лягут в `work/` по хешу содержимого — корзина и её
транскрипты живут рядом, повторные прогоны бесплатные.
