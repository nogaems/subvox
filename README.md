# subvox

Офлайн-субтитры для видео на языках, которых ты не знаешь.

Вход — любой видеофайл, который понимает ffmpeg. Выход — `.srt` рядом с видео,
который mpv подхватывает сам.

## Что делает

1. Декодирует аудиодорожку через ffmpeg.
2. Определяет язык речи. Это самостоятельная ценность: `subvox detect video.mp4`
   отвечает на вопрос «на каком языке это вообще».
3. Распознаёт речь с точностью до слова.
4. Собирает слова в предложения — единица перевода.
5. Переводит на целевой язык.
6. Режет обратно на реплики — единица отображения.
7. Пишет SRT.

## Ключевое архитектурное решение

Единица перевода и единица отображения — разные вещи.

- **Перевод** идёт по предложениям: модели портятся на обрубках, а Whisper режет
  по 30-секундным окнам и рвёт фразы посередине.
- **Отображение** идёт по репликам: ≤2 строки, ≤42 символа, разумная длительность.

Поэтому пайплайн: `слова → предложения → перевод → реплики`, а не
`сегменты Whisper → перевод → сегменты Whisper`.

## Стек

| Слой | Инструмент |
|---|---|
| Декод | ffmpeg (subprocess) |
| VAD | Silero, встроен в faster-whisper |
| ASR | faster-whisper `large-v3`, CTranslate2 |
| LID | Whisper `detect_language` по нескольким окнам + самопроверка |
| Перевод | NLLB-200 через CTranslate2 |
| Запись | pysubs2 |
| CLI | typer |

Нигде нет `torch`: и ASR, и перевод работают на CTranslate2.

## Платформы

| ОС | Статус | Вычисления |
|---|---|---|
| Linux | проверено на живых файлах | GPU — CUDA 12 из venv (опция `[gpu]`) или CPU |
| Windows | спроектировано, не проверено | GPU — только при установленном CUDA Toolkit 12, иначе честный откат на CPU |
| macOS | спроектировано, не проверено | только CPU: GPU-колёс CTranslate2 под macOS не существует |

На CPU обе модели работают в int8, но медленнее в разы — длинное видео
считается примерно в реальном времени. Все пути per-user и платформенно
стандартны: модели и рабочие файлы — в каталоге данных пользователя,
регенерируемое — в каталоге кешей (`paths.py`). ffmpeg требуется
в PATH (Homebrew, winget, пакетный менеджер).

Каталог моделей — мини-хаб Hugging Face: веса лежат в общем хранилище
`blobs/` (дедупликация между моделями), а в каталогы конкретных моделей
указывают относительные симлинки. На Windows без прав на симлинки
(Developer Mode / администратор) huggingface_hub сам заменяет ссылки
копиями файлов — работает, просто чуть больше места на диске.
Относительность ссылок делает каталог переносимым: его можно целиком
перенести на другую машину или в `SUBVOX_HOME` без перекачки весов.

## Установка

```sh
uv tool install --python 3.12 .
```

Для GPU (CUDA 12 + cuDNN 9 кладутся в venv, система не трогается):

```sh
uv tool install --python 3.12 '.[gpu]'
```

## Статус

Работает, полный пайплайн:

- `subvox run video.mp4 --to ru` — распознать, перевести, записать `video.ru.srt`.
  Проверено на живых файлах: en→ru, ru→en, ru→ru (перевод пропускается).
- `subvox list-langs` — все 100 языков: код, название, переводимость NLLB
  (и `--json` для скриптов).
- `--format vtt` у `run`/`transcribe` — субтитры для браузеров (тег `<track>`):
  тот же пайплайн, файл `.vtt` вместо `.srt`.
- `subvox detect video.mp4` — язык речи по нескольким окнам, с альтернативами
  и признаком неуверенности.
- `subvox transcribe video.mp4` — транскрипция с пословными таймкодами,
  черновой `video.<язык>.srt` и `--json`.
- Кеш прогона: повторный прогон того же видео берёт язык и транскрипт
  из рабочего каталога (стандартный каталог данных пользователя
  вашей ОС — см. `paths.py`) — правка целевого языка не гоняет ASR
  заново. Полное попадание не грузит Whisper и не извлекает аудио;
  `--no-cache` считает всё заново.
- Первый запуск без скрытых пауз: отсутствующая модель анонсируется
  («что, сколько, куда») и качается с прогресс-барами; сбой сети —
  человеческая ошибка, а не traceback.
- `subvox.audio` — любая аудиодорожка через ffmpeg в моно float32 16 кГц.
- `subvox.langs` — 100 языков Whisper, 96 из них переводимы через NLLB.
- `subvox.vad` — поиск речи с лестницей порогов: речь поверх музыки
  не выбрасывается как тишина, а помечается как шумная; если речи нет
  совсем, `run` пишет пустой `.srt` с предупреждением.
- `subvox.sentences` — слова → предложения: граница там, где пунктуация
  сошлась с паузой.
- `subvox.nllb` — NLLB-200-distilled-1.3B через CTranslate2, ~90 предложений/с
  на RTX 3060 Ti.
- `subvox.cues` — предложения → реплики: ≤2 строки по 42 символа, CPS
  считается и сообщается, а не урезается; неразрывный бред длиннее двух
  строк пропускается с предупреждением, тайминги соседей не меняются.

## Первый живой прогон

Перед v1 пайплайн прогнан целиком на корпусе из 16 живых видео (8.1 ч
аудио): длинный монолог, студийная речь, кокни, андалузский и
доминиканский испанский, хинглиш, бразильский португальский, тайваньский
мандарин, кантонский, японский, казахский, немецкий, египетский арабский —
и три файла, которые должны ломаться по дизайну.

Результат: **16/16 файлов**. Пятнадцать слотов дали содержательные
субтитры; `fail-nospeech` (музыка без речи) — пустой `.srt` (0 реплик)
с явным предупреждением «речи не найдено». Это не выдуманный текст:
распознавать было нечего, поэтому `detect` на нём по-прежнему завершается
ошибкой. Перевод шёл на CUDA, `ru→ru` пропустил перевод, кеш транскриптов
отработал. Всего на 13 рабочих слотах — **4049 предложений и 6512 реплик**;
строк длиннее 42 знаков в готовых файлах нет. Корзина и её оси нагрузки —
`contrib/smoke-videos.md`, прогон — `contrib/run_smoke.py`.

### Фейловые слоты (3, by design)

| Слот | Что проверял | Результат |
|---|---|---|
| `fail-trailer` | диалог поверх оркестровки | 41 / 45; текст обрубками — сообщается, не лечится |
| `fail-singing` | пение | 9 / 9; галлюцинации отфильтрованы частично |
| `fail-nospeech` | только музыка, речи нет | пустой `.srt` (0 реплик) + предупреждение; `detect` — ошибка |

**Как читать эти таблицы.** Три фейловые строки — не «баги прогона»
и не часть общей статистики: они измеряют известные ограничения v1
(речь поверх музыки, пение, отсутствие речи) и нужны, чтобы отличать
регресс от нормы и кормить дорожную карту фактами. Об надёжности
инструмента они не говорят ничего — для этого есть таблица рабочих
слотов выше.

## Дорожная карта

- **Установочные скрипты** — написаны (`install.sh`, `install.ps1`), но это
  пока попытка, а не проверенное решение: shell-путь прогнан на Linux
  (из исходника), PowerShell под Windows не проверялся — проверится при
  первом деплое на живой машине. Бандл в экзешник отвергнут: ffmpeg
  и CUDA-библиотеки в него всё равно не упаковать, а onefile
  распаковывается при каждом вызове. Скрипт запускается перед установкой
  и подтягивает всё нужных версий: ffmpeg системным пакетным менеджером,
  uv с питоном 3.12, wheel subvox из GitHub Releases. Модели в пакет
  не входят — скачиваются при первом запуске в стандартный каталог
  пользователя.

Отвергнуто: формат ASS. Позиционирование реплик и стили предполагают
знание, кто говорит и где — у нас нет диаризации, и она вне скоупа
проекта. VTT добавлен: это стандарт браузерных субтитров, а плееры
и так едят оба формата.
