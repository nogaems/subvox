# subvox

Офлайн-субтитры для видео на языках, которых ты не знаешь.

Вход — любой видеофайл, который понимает ffmpeg. Выход — `.srt` рядом с видео,
который mpv подхватывает сам.

## Что делает

1. Декодирует аудиодорожку через ffmpeg.
2. Определяет язык речи. Это самостоятельная ценность: `subvox detect video.mp4`
   отвечает на вопрос «на каком языке это вообще».
3. Распознаёт речь с точностью до слова.
4. Собирает слова в предложения — единица перевода.
5. Переводит на целевой язык.
6. Режет обратно на реплики — единица отображения.
7. Пишет SRT.

## Ключевое архитектурное решение

Единица перевода и единица отображения — разные вещи.

- **Перевод** идёт по предложениям: модели портятся на обрубках, а Whisper режет
  по 30-секундным окнам и рвёт фразы посередине.
- **Отображение** идёт по репликам: ≤2 строки, ≤42 символа, разумная длительность.

Поэтому пайплайн: `слова → предложения → перевод → реплики`, а не
`сегменты Whisper → перевод → сегменты Whisper`.

## Стек

| Слой | Инструмент |
|---|---|
| Декод | ffmpeg (subprocess) |
| VAD | Silero, встроен в faster-whisper |
| ASR | faster-whisper `large-v3`, CTranslate2 |
| LID | Whisper `detect_language` по нескольким окнам + самопроверка |
| Перевод | NLLB-200 через CTranslate2 |
| Запись | pysubs2 |
| CLI | typer |

Нигде нет `torch`: и ASR, и перевод работают на CTranslate2.

## Установка

```sh
uv tool install --python 3.12 .
```

Для GPU (CUDA 12 + cuDNN 9 кладутся в venv, система не трогается):

```sh
uv tool install --python 3.12 '.[gpu]'
```

## Статус

Работает, полный пайплайн:

- `subvox run video.mp4 --to ru` — распознать, перевести, записать `video.ru.srt`.
  Проверено на живых файлах: en→ru, ru→en, ru→ru (перевод пропускается).
- `subvox detect video.mp4` — язык речи по нескольким окнам, с альтернативами
  и признаком неуверенности.
- `subvox transcribe video.mp4` — транскрипция с пословными таймкодами,
  черновой `video.<язык>.srt` и `--json`.
- `subvox.audio` — любая аудиодорожка через ffmpeg в моно float32 16 кГц.
- `subvox.langs` — 100 языков Whisper, 96 из них переводимы через NLLB.
- `subvox.vad` — поиск речи с лестницей порогов: речь поверх музыки
  не выбрасывается как тишина, а помечается как шумная.
- `subvox.sentences` — слова → предложения: граница там, где пунктуация
  сошлась с паузой.
- `subvox.nllb` — NLLB-200-distilled-1.3B через CTranslate2, ~90 предложений/с
  на RTX 3060 Ti.
- `subvox.cues` — предложения → реплики: ≤2 строки по 42 символа, CPS
  считается и сообщается, а не урезается.

Дальше: кэш транскрипта (не гонять ASR повторно при правках), `--list-langs`,
VTT/ASS.
